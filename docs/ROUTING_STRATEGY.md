# Routing Strategy

## Routing levels
1. explicit model selection
2. policy constrained auto-routing
3. rule-based routing by task/cost/latency/risk
4. semantic routing (future)
5. adaptive routing by provider health (future)

## Routing dimensions
- capability
- cost
- latency
- region
- risk
- token/context limits
- feature support (json mode, tools, streaming)
