# Shuffles test order, which is how this suite's shared-state bugs get
# caught at all (FIX55, FIX56.1). It was already installed in the test
# image and declared NOWHERE, so the release gate's answer could change
# with no commit behind it — the reason it is written down now.
#
# The seed is pinned in pyproject.toml, and that is load-bearing, not
# tidiness: _reseed() computes ``randomly_seed + offset`` where the
# offset is a CRC32, clamps that for its OWN numpy call
# (``seed % 2**32``) and then hands the UNCLAMPED value to every
# ``pytest_randomly.random_seeder`` entry point. thinc ships one (it
# arrives with spaCy/Presidio, the NER stage) and calls
# ``numpy.random.seed`` without the clamp, so a time-derived default
# seed overflows and every test errors in setup AND teardown — 6276 of
# them, before anything is measured. Seed 0 keeps every offset in range.
