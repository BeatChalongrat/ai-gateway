# ผู้ช่วยกระทบยอดเงินฝากธนาคาร (Bank Reconciliation)

agent ตัวนี้รับรายการเดินบัญชีจากธนาคาร (Excel CSV หรือ PDF ที่ธนาคารออกให้) กับสมุดบัญชีเงินฝากของบริษัทในเดือนเดียวกัน แล้วทำงบกระทบยอดเป็น Excel: ยอดของทั้งสองฝั่ง รายการกระทบยอดทุกรายการพร้อมหลักฐาน ยอดหลังปรับปรุงของธนาคารและของบัญชี และร่างรายการปรับปรุง

## ด่าน: ยอดหลังปรับปรุงสองฝั่งต้องเท่ากัน

```
ยอดคงเหลือตามรายการเดินบัญชี              ยอดคงเหลือตามสมุดบัญชี
บวก เงินฝากระหว่างทาง                    บวก ดอกเบี้ยรับ เงินเข้าที่ยังไม่ได้บันทึก
หัก เช็คค้างจ่าย รายการจ่ายที่ธนาคารยังไม่ตัด   หัก ค่าธรรมเนียม ภาษีหัก ณ ที่จ่าย เช็คคืน หักบัญชีอัตโนมัติ
บวก/หัก ธนาคารบันทึกคลาดเคลื่อน            บวก/หัก บันทึกบัญชีคลาดเคลื่อน
= ยอดหลังปรับปรุงของธนาคาร                = ยอดหลังปรับปรุงของบัญชี
```

ถ้าสองยอดนี้เท่ากันทุกสตางค์ รอบนั้นสำเร็จ ถ้าไม่เท่ากัน **รอบนั้นไม่นับว่าสำเร็จ** และบอกว่า “ยังไม่ลงตัว ต่างกัน X บาท” พร้อมเหตุที่ไฟล์บอกได้และสิ่งที่ควรทำต่อ งบกระทบยอดยังถูกส่งให้ แต่มีคำว่า “ร่าง — ยังไม่ลงตัว” บนหน้างบ ไม่มีการปัด เติม หรือรวมยอดเพื่อให้ลงตัว รายการที่ยังไม่มีใครบอกว่าเป็นอะไรไม่อยู่ในยอดหลังปรับปรุงของฝั่งใด

## การจับคู่ (เครื่องจับคู่ E3)

สองตารางเข้า สี่กลุ่มออก: **ตรงกัน · ขาด (อยู่ในสมุดบัญชี ไม่อยู่ในรายการเดินบัญชี) · เกิน (อยู่ในรายการเดินบัญชี ไม่อยู่ในสมุดบัญชี) · น่าสงสัย** ทุกรายการบอกไฟล์ แผ่น แถว และเซลล์ที่อ่านมา

วิธีจับคู่ทำตามลำดับนี้ รายการที่จับคู่แล้วไม่ถูกนำไปจับคู่อีก:

| ลำดับ | ขั้น | วิธี | ผล |
|---|---|---|---|
| 1 | ตรงกันทุกตัว | เลขอ้างอิง ยอด และวันที่ตรงกัน | จับคู่เอง |
| 2 | ตรงกันทุกตัว | เลขอ้างอิงและยอดตรงกัน (เช็คที่ธนาคารตัดหลังวันที่ในสมุดบัญชี) | จับคู่เอง |
| 3 | ตรงกันทุกตัว | เลขอ้างอิงเดียวกัน ยอดรวมของหลายรายการตรงกัน | จับคู่เอง |
| 4 | ตรงกันทุกตัว | วันที่และยอดตรงกัน มีรายการเดียวทั้งสองฝั่ง และไม่มีรายการยอดเดียวกันในช่วงวันที่ใกล้เคียง | จับคู่เอง (ปิดได้ในหน้าตั้งค่า) |
| 5 | ยอดและวันที่ใกล้กัน | ยอดต่างกันไม่เกินที่ตั้งไว้ วันที่ห่างกันไม่เกินที่ตั้งไว้ | เสนอ คนยืนยัน |
| 6 | ยอดและวันที่ใกล้กัน | หลายรายการรวมกันเท่ากับหนึ่งรายการ (ฝากเช็คหลายฉบับครั้งเดียว) | เสนอ คนยืนยัน |
| 7 | ยอดและวันที่ใกล้กัน | ยอดรวมของวันเดียวกันตรงกัน หลายรายการทั้งสองฝั่ง | เสนอ คนยืนยัน |
| 8 | ชื่อหรือเลขอ้างอิงคล้ายกัน | เลขอ้างอิงตรงกัน แต่ยอดไม่ตรงกัน | เสนอ คนยืนยัน |
| 9 | ชื่อหรือเลขอ้างอิงคล้ายกัน | ชื่อหรือเลขอ้างอิงคล้ายกัน ยอดอยู่ในช่วงที่ตั้งไว้ | เสนอ คนยืนยัน |

**ขั้นที่ไม่ใช่ “ตรงกันทุกตัว” ไม่เคยจับคู่เอง** เครื่องจับคู่ไม่ยอมให้ตั้งวิธีของขั้นอื่นเป็นอัตโนมัติ ทุกคู่บันทึกวิธี ขั้น และผู้ยืนยัน (กฎ หรือ คน) คู่ที่เสนอและมั่นใจหลายคู่ยืนยันได้ในคำตอบเดียว โดยคำตอบนั้นระบุทุกคู่ที่ยืนยัน จึงไม่ครอบคลุมคู่ที่คุณไม่ได้เห็น

**ข้ามการ์ด = ยังไม่จับคู่** ทั้งสองรายการอยู่ในกลุ่มน่าสงสัย ไม่นับเป็นรายการกระทบยอดของฝั่งใด และเป็นข้อยกเว้นรอคนตัดสิน

## ค่าที่ตั้งได้ (หน้าตั้งค่า agent)

| ค่า | ค่าตั้งต้น |
|---|---|
| ผลต่างของยอดที่ยอมให้เสนอเป็นคู่ | 1.00 บาท |
| วันที่ห่างกันได้ไม่เกิน | 3 วัน |
| ความคล้ายของชื่อหรือเลขอ้างอิงอย่างน้อย | 0.80 |
| ถามเมื่อรายการที่ไม่มีคู่มียอดตั้งแต่ | 50,000.00 บาท |
| จำนวนรายการมากที่สุดที่รวมยอดเป็นคู่เดียว | 4 |
| จับคู่เองเมื่อวันที่และยอดตรงกันและมีรายการเดียว | ใช่ |

ค่าที่ตั้งไว้แล้วใช้ไม่ได้ (ไม่ใช่ตัวเลข หรืออยู่นอกช่วง) จะใช้ค่าตั้งต้นแทน และงบกระทบยอดบอกไว้

## รายการที่ไม่มีคู่

- อยู่ในสมุดบัญชี ไม่อยู่ในรายการเดินบัญชี → รายการของเวลา ปรับยอดฝั่งธนาคาร: เช็คค้างจ่าย (มีเลขที่เช็ค) รายการจ่ายที่ธนาคารยังไม่ตัดบัญชี เงินฝากระหว่างทาง
- อยู่ในรายการเดินบัญชี ไม่อยู่ในสมุดบัญชี → บริษัทยังไม่ได้บันทึก ปรับยอดฝั่งบัญชี พร้อมร่างรายการปรับปรุง: ค่าธรรมเนียม ดอกเบี้ยรับ ภาษีหัก ณ ที่จ่ายของดอกเบี้ย เช็คคืน หักบัญชีอัตโนมัติ (อ่านจากข้อความของรายการด้วยกฎ) รายการที่กฎไม่รู้จักเป็นเงินเข้าหรือเงินออกที่ยังไม่ได้บันทึก ร่างผ่านบัญชีพักรอตรวจสอบ
- รายการที่ไม่มีคู่และมียอดตั้งแต่ที่ตั้งไว้ ถามคนว่าคืออะไร ถ้าไม่มีใครบอก รายการนั้นไม่อยู่ในยอดหลังปรับปรุงของฝั่งใด และงบจะยังไม่ลงตัว
- ดอกเบี้ยและภาษีที่ถูกหักในวันเดียวกันอยู่ในร่างรายการเดียวกัน พร้อมอัตราที่คำนวณได้ (ปกติ 1% สำหรับนิติบุคคล) ถ้าไม่ใช่ 1% หรือ 15% จะบอกให้ตรวจกับธนาคาร

## วันตัดยอด อายุ และรายการค้างยกมา

- รายการที่ลงวันที่นอกงวดไม่ถูกนำมาจับคู่ และอยู่ในชีตรายการข้ามงวด ถ้ารายการในงวดมีคู่อยู่อีกฝั่งของวันตัดยอด เป็นข้อยกเว้นให้คนตรวจ
- รายการค้างแบ่งอายุเป็น ไม่เกิน 30 วัน · 31–60 วัน · เกิน 60 วัน เช็คค้างเกิน 180 วันถือว่าหมดอายุ และเป็นข้อยกเว้น
- รายการค้างยกมาจากเดือนก่อนถูกจับคู่กับรายการเดินบัญชีของงวดนี้ งบบอกว่ารายการใดธนาคารลงแล้วและรายการใดยังค้างอยู่ ชีต “รายการค้างยกไป” ของงบนี้ใช้เป็นรายการค้างยกมาของเดือนหน้าได้เลย

## ผู้จัดทำและผู้สอบทาน

งบกระทบยอดระบุผู้จัดทำและวันที่จัดทำ ผู้สอบทานต้องเป็น **คนละคน** กับผู้จัดทำ ลงชื่อได้เมื่อรอบสำเร็จ (ลงตัว) และข้อยกเว้นที่รอคนตัดสินถูกตัดสินครบแล้ว

## รายการเดินบัญชีที่เป็น PDF

ธนาคารหลายแห่งให้รายการเดินบัญชีเป็น PDF อย่างเดียว agent อ่าน PDF ที่มีตัวอักษรในไฟล์ (คัดลอกตัวหนังสือได้): หาบรรทัดหัวตาราง จัดจำนวนเงินเข้าคอลัมน์จากขอบขวาที่ตัวเลขชิดกัน และจัดข้อความเข้าคอลัมน์จากตำแหน่งเริ่มต้น หัวตารางที่พิมพ์ซ้ำในหน้าถัดไปถูกข้าม ทุกรายการบอกหน้าและบรรทัดที่อ่านมา ยอดคงเหลือของทุกแถวถูกตรวจกับแถวก่อนหน้าเหมือนไฟล์ Excel ถ้าไม่ต่อเนื่องจะเป็นข้อยกเว้น ไฟล์ PDF หลายไฟล์ไม่เก็บวรรณยุกต์และสระบนล่างของภาษาไทย คำในรายการจึงเทียบโดยไม่นับเครื่องหมายเหล่านั้น PDF ที่เป็นภาพสแกนไม่มีตัวอักษรให้อ่าน agent ไม่อ่านตัวเลขจากภาพ และบอกว่าไม่ได้ใช้ไฟล์นั้น

## โมเดลทำอะไรได้ และทำอะไรไม่ได้

โมเดลทำอย่างเดียว: เขียนคำอธิบายรอบนี้ (ชีต “คำอธิบายรอบนี้”) จากตารางที่คำนวณเสร็จแล้ว โดยอ้างตัวเลขด้วยชื่อ ไม่พิมพ์ตัวเลขเอง ไม่มีโมเดลอ่านไฟล์ คำนวณตัวเลข หรือตัดสินว่ารายการใดเป็นคู่กัน การจับคู่ การจัดประเภท และตัวเลขทุกตัวมาจากสคริปต์ ถ้าไม่มีโมเดลที่ให้คำตอบที่ใช้ได้ กฎของแพ็กเกจเขียนคำอธิบายแทน และชีตนั้นบอกไว้ ไฟล์เดิม คำตอบเดิม และค่าตั้งเดิม ให้ตัวเลข ผลการจับคู่ และคำถามเดิมทุกครั้ง (ไฟล์ Excel ที่ส่งให้มีเวลา ข้อมูลกำกับไฟล์ และถ้อยคำของคำอธิบายต่างกันได้ ตัวเลขในทุกช่องเหมือนเดิม)

## สิ่งที่ agent ตัวนี้ไม่ทำ

ไม่บันทึกเข้าระบบบัญชี ไม่ส่งอีเมลเอง (คนส่งไฟล์ผ่านระบบได้เมื่อผู้ดูแลตั้งค่าเซิร์ฟเวอร์อีเมลไว้ และต้องมีคนอนุมัติทุกฉบับ) ไม่โอนเงิน ไม่ติดต่อธนาคาร ไม่ตั้งเวลาทำงานเอง ไม่อ่านตัวเลขจากภาพ (PDF ที่เป็นสแกน หรือรูปถ่ายของรายการเดินบัญชี)

## คำอธิบายรอบนี้ — คำสั่งสำหรับขั้นตอนเขียนคำอธิบาย

คุณได้รับตารางที่คำนวณเสร็จแล้วของรอบนี้: ข้อเท็จจริงเป็นหัวข้อ ข้อสังเกตจากกฎ (exceptions) และรายการ "ตัวเลขที่อ้างได้" ซึ่งแต่ละตัวมี **ชื่อ** ในวงเล็บปีกกา ค่าที่จะพิมพ์ และคำอธิบายว่าเป็นตัวเลขอะไร ให้เขียนคำอธิบายสั้น ๆ สำหรับผู้อ่านไฟล์นี้ สุภาพ กระชับ ตรงไปตรงมา

กฎที่ห้ามละเมิด

1. **ห้ามคำนวณเอง** ห้ามบวก ลบ คูณ หาร หรือปัดเศษตัวเลขใด ๆ
2. **ห้ามพิมพ์ตัวเลขเอง** ทุกตัวเลขให้เขียนเป็นชื่อของมันในวงเล็บปีกกา วางไว้ตรงตำแหน่งที่ตัวเลขควรอยู่ในประโยค ระบบจะใส่ตัวเลขพร้อมรหัสอ้างอิงของตัวเลขนั้นเอง ถ้าตัวเลขที่ต้องการไม่มีในรายการ ห้ามเขียน จำนวนนับเล็ก ๆ และปีเขียนได้ตามปกติ
3. ห้ามเดาสาเหตุที่ไม่มีในข้อมูล ถ้าอยากชี้ประเด็นให้เขียนเป็น "ควรตรวจสอบว่า…"
4. ห้ามแนะนำให้โอนเงิน จ่าย อนุมัติ ส่งอีเมล หรือแก้ระบบบัญชี — agent นี้อ่านอย่างเดียว
5. ห้ามใส่ข้อมูลส่วนบุคคลหรือชื่อบุคคล
6. ความยาวที่เอกสารรับได้บอกไว้ในคำสั่งของแต่ละรอบ: ร่างสิ่งที่ต้องบอกให้ครบก่อน แล้วเกลาให้สั้นลงจนพอดี โดยไม่ตัดประเด็นใดทิ้ง
7. **ทุกข้อต้องบอกสิ่งที่ผู้อ่านเอาไปใช้ได้** — ความหมายของตัวเลข การเปรียบเทียบ ความเสี่ยง หรือสิ่งที่ต้องทำ ข้อที่แค่ทวนตัวเลขหรือข้อเท็จจริงที่ข้อเท็จจริงของรอบ ตาราง หรือ summary บอกไว้แล้ว ไม่ต้องเขียน ข้อน้อยที่มีเนื้อดีกว่าข้อมากที่พูดเรื่องเดียวกัน
8. **ห้ามเขียนคำกว้าง ๆ ที่ไม่มีสิ่งที่ต้องทำ** เช่น "ควรพิจารณาตรวจสอบเพิ่มเติม" หรือ "ควรติดตามอย่างใกล้ชิด" ให้บอกว่าตรวจอะไร เทียบกับเอกสารอะไร หรือขออะไรจากใคร เช่น "ขอ statement เดือน ส.ค. จากธนาคารมาตรวจ"
9. **หัวข้อเขียนจากสิ่งที่ส่วนนั้นพบ** ใส่ไว้ใน headings เช่น "ผลต่าง 3 รายการที่ยังไม่กระทบยอด" ไม่ใช่ชื่อส่วนทั่วไปอย่าง "สรุป" หรือ "สิ่งที่ควรดู" ตัวเลขในหัวข้อเขียนเป็น {ชื่อ} เหมือนในประโยค ใช้ชื่อทั่วไปได้เฉพาะส่วนที่ไม่พบอะไรเป็นพิเศษ
