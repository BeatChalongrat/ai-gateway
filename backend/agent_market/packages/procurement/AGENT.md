# ผู้ช่วยจัดซื้อ

Agent นี้รับคำขอซื้อเป็นข้อความ ค้นหาผู้ขายบนเว็บ บันทึกหน้าสินค้าไว้เป็นหลักฐาน ทำตารางเทียบตัวเลือกให้คนเลือก แล้วร่างใบขอซื้อจากตัวเลือกที่คนเลือก

## สิ่งที่โมเดลทำ และสิ่งที่โปรแกรมทำ

- โมเดลอ่านคำขอ (prompts/brief.md) เขียนคำค้น (prompts/plan.md) เลือกผลการค้นหาที่จะเปิด (prompts/select.md) และอ่านหน้าที่บันทึกไว้ (prompts/read.md) โมเดลไม่มีเครื่องมือใดๆ ตอบได้เฉพาะข้อมูลตามรูปแบบที่กำหนด
- โปรแกรมตรวจทุกค่าที่โมเดลอ่านได้กับหน้าที่บันทึกไว้ คำนวณยอดรวมและภาษี ตัดสินว่าแหล่งใดใช้ได้ และเขียนเอกสาร ค่าที่หาไม่พบในหน้าที่บันทึกไว้จะไม่อยู่ในตาราง
- คนเป็นผู้เลือกตัวเลือก ตรวจร่าง กรอกช่องที่ยังขาด และส่งใบขอซื้อเอง

## สิ่งที่ agent ไม่ทำ

ไม่สั่งซื้อ ไม่ขอใบเสนอราคา ไม่ส่งอีเมล ไม่ส่งหรืออนุมัติใบขอซื้อ ไม่เข้าหน้าที่ต้องเข้าสู่ระบบ ไม่ผ่านการยืนยันว่าเป็นคน และไม่เดาสิ่งที่หน้าเว็บไม่ได้บอก

ไม่มีส่วนใดของ agent นี้ที่เขียนไว้สำหรับของชนิดใดชนิดหนึ่ง ข้อกำหนดคือคำของผู้ขอ และค่าทุกค่าคือข้อความจากหน้าเว็บ
