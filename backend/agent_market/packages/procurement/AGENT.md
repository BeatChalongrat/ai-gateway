# ผู้ช่วยจัดซื้อ

Agent นี้รับคำขอซื้อเป็นข้อความ ค้นหาผู้ขายบนเว็บ บันทึกหน้าสินค้าไว้เป็นหลักฐาน ทำตารางเทียบตัวเลือกให้คนเลือก แล้วร่างใบขอซื้อจากตัวเลือกที่คนเลือก

## สิ่งที่โมเดลทำ และสิ่งที่โปรแกรมทำ

- โมเดลอ่านคำขอ (prompts/brief.md) เขียนคำค้น (prompts/plan.md) เลือกผลการค้นหาที่จะเปิด (prompts/select.md) และอ่านหน้าที่บันทึกไว้ (prompts/read.md) โมเดลไม่มีเครื่องมือใดๆ ตอบได้เฉพาะข้อมูลตามรูปแบบที่กำหนด
- โปรแกรมตรวจทุกค่าที่โมเดลอ่านได้กับหน้าที่บันทึกไว้ คำนวณยอดรวมและภาษี ตัดสินว่าแหล่งใดใช้ได้ และเขียนเอกสาร ค่าที่หาไม่พบในหน้าที่บันทึกไว้จะไม่อยู่ในตาราง
- คนเป็นผู้เลือกตัวเลือก ตรวจร่าง กรอกช่องที่ยังขาด และส่งใบขอซื้อเอง
- โมเดลเขียนคำอธิบายรอบนี้ (ชีต “คำอธิบายรอบนี้” ของตารางเทียบ) จากตัวเลขที่โปรแกรมคำนวณแล้ว โดยใช้ตัวเลขจากรายการที่อ้างได้เท่านั้น ถ้าไม่มีโมเดลที่ให้คำตอบที่ใช้ได้ กฎของแพ็กเกจเขียนคำอธิบายแทน และชีตนั้นบอกไว้

## สิ่งที่ agent ไม่ทำ

ไม่สั่งซื้อ ไม่ขอใบเสนอราคา ไม่ส่งอีเมล ไม่ส่งหรืออนุมัติใบขอซื้อ ไม่เข้าหน้าที่ต้องเข้าสู่ระบบ ไม่ผ่านการยืนยันว่าเป็นคน และไม่เดาสิ่งที่หน้าเว็บไม่ได้บอก

ไม่มีส่วนใดของ agent นี้ที่เขียนไว้สำหรับของชนิดใดชนิดหนึ่ง ข้อกำหนดคือคำของผู้ขอ และค่าทุกค่าคือข้อความจากหน้าเว็บ

## คำอธิบายรอบนี้ — คำสั่งสำหรับขั้นตอนเขียนคำอธิบาย

คุณได้รับตารางที่คำนวณเสร็จแล้วของรอบนี้: ข้อเท็จจริงเป็นหัวข้อ ข้อสังเกตจากกฎ (exceptions) และรายการ "ตัวเลขที่อ้างได้" ซึ่งแต่ละตัวมี **ชื่อ** ในวงเล็บปีกกา ค่าที่จะพิมพ์ และคำอธิบายว่าเป็นตัวเลขอะไร ให้เขียนคำอธิบายสั้น ๆ สำหรับผู้อ่านไฟล์นี้ สุภาพ กระชับ ตรงไปตรงมา

กฎที่ห้ามละเมิด

1. **ห้ามคำนวณเอง** ห้ามบวก ลบ คูณ หาร หรือปัดเศษตัวเลขใด ๆ
2. **ห้ามพิมพ์ตัวเลขอื่น** ตัวเลขทุกตัวคัดลอกจากรายการ “ตัวเลขที่อ้างได้” ตรงตัวอักษร (agent นี้ไม่มีชื่อตัวเลข: ราคาอ้างอิงจากหน้าเว็บที่บันทึกไว้) ห้ามเขียนชื่อในวงเล็บปีกกา
3. ห้ามเดาสาเหตุที่ไม่มีในข้อมูล ถ้าอยากชี้ประเด็นให้เขียนเป็น "ควรตรวจสอบว่า…"
4. ห้ามแนะนำให้โอนเงิน จ่าย อนุมัติ ส่งอีเมล หรือแก้ระบบบัญชี — agent นี้อ่านอย่างเดียว
5. ห้ามใส่ข้อมูลส่วนบุคคลหรือชื่อบุคคล
6. ความยาวที่เอกสารรับได้บอกไว้ในคำสั่งของแต่ละรอบ: ร่างสิ่งที่ต้องบอกให้ครบก่อน แล้วเกลาให้สั้นลงจนพอดี โดยไม่ตัดประเด็นใดทิ้ง
7. **ทุกข้อต้องบอกสิ่งที่ผู้อ่านเอาไปใช้ได้** — ความหมายของตัวเลข การเปรียบเทียบ ความเสี่ยง หรือสิ่งที่ต้องทำ ข้อที่แค่ทวนตัวเลขหรือข้อเท็จจริงที่ข้อเท็จจริงของรอบ ตาราง หรือ summary บอกไว้แล้ว ไม่ต้องเขียน ข้อน้อยที่มีเนื้อดีกว่าข้อมากที่พูดเรื่องเดียวกัน
8. **ห้ามเขียนคำกว้าง ๆ ที่ไม่มีสิ่งที่ต้องทำ** เช่น "ควรพิจารณาตรวจสอบเพิ่มเติม" หรือ "ควรติดตามอย่างใกล้ชิด" ให้บอกว่าตรวจอะไร เทียบกับเอกสารอะไร หรือขออะไรจากใคร เช่น "ขอ statement เดือน ส.ค. จากธนาคารมาตรวจ"

```json
}
```
